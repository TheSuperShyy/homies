# סקיל שפה — הבחנת מין, הגייה מושלמת וחלופות בטוחות (עברית)

> הסקיל הזה פותר את הבעיה הכי גדולה של סוכן קולי בעברית: **עברית נכתבת בלי ניקוד, אבל נשמעת עם ניקוד.** מילה אחת כתובה יכולה להישמע בחמש דרכים. סוכן שלא יודע להבחין — יישמע שבור. סוכן שיודע — נשמע כמו בן אדם.
> המסמך בנוי בשלושה חלקים: (1) הבחנת מין — פנייה ללקוח ודיבור על עצמך; (2) הומוגרפים שה-TTS הורס והגייה מדויקת; (3) מאגר ענק של חלופות למילים מועדות לפורענות.

# חלק א' — הבחנת מין (זכר/נקבה)

זו הבעיה מספר אחת בעברית מדוברת. בשונה מאנגלית, בעברית **כמעט כל משפט משתנה** לפי מין הנמען ומין הדובר. סוכן שפונה ל"אדוני" ל"את" בטעות — נשרף מיד.

## 1. שתי שאלות שהסוכן חייב לענות עליהן בכל שיחה

**שאלה 1 — מה מין הלקוח שאיתי מדבר?** (קובע איך אני פונה אליו)
**שאלה 2 — מה המין של הפרסונה שלי?** (קובע איך אני מדבר על עצמי)

שתי השאלות בלתי-תלויות. סוכנת (נקבה) שמדברת עם גבר: היא אומרת "אני **בדקתי**" (נקבה, על עצמה) ו"מה **אתה** צריך" (זכר, אל הלקוח).

## 2. איך הסוכן מזהה את מין הלקוח

לפי סדר עדיפות:

1. **CRM / נתוני מערכת** — אם המספר מזוהה ויש שם, ברוב המקרים אפשר להסיק מין מהשם. תעביר את זה לפרומפט: "שם הלקוח: דנה → נקבה".
2. **השם שהלקוח מוסר** — "מדברת רותי" → נקבה. "מדבר אבי" → זכר.
3. **הטיות בדיבור של הלקוח על עצמו** — "אני צריכה" → נקבה. "אני רוצה לקבוע" (נייטרלי) → עדיין לא ידוע.
4. **הקול** — לא אמין ב-100%, אבל אות עזר. אל תסתמך רק עליו.

**החוק הקריטי — עד שאתה יודע, דבר נייטרלי:**
כל עוד מין הלקוח לא ודאי, השתמש בניסוחים חסרי-מין (ראה סעיף 4). אף פעם אל תנחש. פנייה שגויה במין = הפגיעה הכי גדולה באמון בשיחה עברית.

## 3. טבלת ההטיות המלאה — פנייה ללקוח

| כוונה | לגבר (זכר) | לאישה (נקבה) |
|---|---|---|
| אתה/את | אַתָּה | אַתְּ |
| שלך | שֶׁלְּךָ (shelkha) | שֶׁלָּךְ (shelakh) |
| לך | לְךָ (lekha) | לָךְ (lakh) |
| איתך | אִתְּךָ (itkha) | אִתָּךְ (itakh) |
| בשבילך | בִּשְׁבִילְךָ | בִּשְׁבִילֵךְ |
| אצלך | אֶצְלְךָ | אֶצְלֵךְ |
| ממך | מִמְּךָ | מִמֵּךְ |
| עליך | עָלֶיךָ | עָלַיִךְ |
| רוצה | רוֹצֶה | רוֹצָה |
| צריך | צָרִיךְ | צְרִיכָה |
| יכול | יָכוֹל | יְכוֹלָה |
| מבין | מֵבִין | מְבִינָה |
| בוא | בּוֹא | בּוֹאִי |
| תגיד | תַּגִּיד | תַּגִּידִי |
| תשמע | תִּשְׁמַע | תִּשְׁמְעִי |
| תבדוק | תִּבְדֹּק | תִּבְדְּקִי |
| תרשום | תִּרְשֹׁם | תִּרְשְׁמִי |
| שלום לך | שָׁלוֹם לְךָ | שָׁלוֹם לָךְ |
| מוזמן | מוּזְמָן | מוּזְמֶנֶת |
| מרוצה | מְרוּצֶה | מְרוּצָה |
| חוזר אליך | חוֹזֵר אֵלֶיךָ | חוֹזֵר אֵלַיִךְ |

**זו נקודת הכשל הכי נפוצה:** ל-ך. **לְךָ** (lekha) לגבר, **לָךְ** (lakh) לאישה. אותו כתיב בדיוק, שתי הגיות. ה-TTS צריך לדעת איזו.

## 4. הזהב — הניסוחים הנייטרליים (חסרי מין)

**זה הכלי הכי חשוב במסמך.** כשאתה לא בטוח במין הלקוח, או כשאתה רוצה להימנע מסיכון, יש דרכים לומר את אותו הדבר בלי לחשוף מין:

| במקום (מסוכן) | נייטרלי (בטוח) |
|---|---|
| "אתה צריך..." / "את צריכה..." | "צריך..." / "יש צורך ב..." |
| "מה אתה רוצה?" | "מה תרצו?" / "איך אפשר לעזור?" |
| "אתה מוזמן" | "מוזמנים" / "אפשר בשמחה" |
| "תגיד לי" / "תגידי לי" | "אפשר לדעת?" / "מעניין אותי לשמוע" |
| "בוא נראה" / "בואי נראה" | "בואו נראה" / "נראה רגע" |
| "תשלח לי" | "אפשר לשלוח?" / "מחכה לזה במייל" |
| "אתה מבין?" | "זה ברור?" / "עובר טוב?" |
| "שלך" | "של [שם]" / "ההזמנה" / "התיק" |
| "חוזר אליך" | "חוזרים בהקדם" / "יהיה עדכון" |
| "כמה אתה משלם?" | "מה התקציב?" / "על איזה סכום מדובר?" |
| "אתה בטוח?" | "זה סופי?" / "נסגור על זה?" |

**טקטיקה:** בשלושת המשפטים הראשונים של השיחה — לפני שאתה יודע מין — דבר נייטרלי. ברגע שהלקוח חושף מין (בשם או בהטיה), עבור להטיה הנכונה. זה בדיוק מה שבן אדם עושה באופן לא-מודע.

## 5. פנייה מכבדת בלי מין ודאי

- **"שלום"** — נייטרלי לחלוטין. תמיד בטוח.
- **"היי"** — נייטרלי, קליל.
- לפי שם: **"שלום דנה"** / **"היי אבי"** — אם יש שם, זו הפנייה הכי חמה ובטוחה.
- **הימנע מ"אדוני" / "גברתי"** אלא אם הפרסונה מאוד פורמלית — זה נשמע מיושן ולפעמים שגוי.

## 6. מין הפרסונה — דיבור על עצמך

הפרסונה שלך היא זכר או נקבה, וזה קבוע לאורך כל השיחות. ודא עקביות:

**פרסונה נקבה (למשל רחל, מיכל, נועה):**
"אני **בדקתי** לך", "אני **אשמח**", "אני **חוזרת** אלייך", "אני **מבינה** אותך", "**רשמתי**", "אני **אהיה** פה".

**פרסונה זכר (למשל עומר, איתן, שלומי):**
"אני **בדקתי** לך" (עבר זהה!), "אני **אשמח**", "אני **חוזר** אליך", "אני **מבין** אותך", "**רשמתי**" (עבר זהה!), "אני **אהיה** פה".

**שים לב:** בזמן **עבר** ההטיה של גוף ראשון זהה לזכר ונקבה! "בדקתי", "רשמתי", "אמרתי", "שלחתי" — זהה. ההבדל הוא רק ב**הווה ובעתיד**: "בודק/בודקת", "אחזור/אני חוזרת". זו נקודה שמבלבלת מודלים — הדגש אותה.

## 7. סצנת אימון — הבחנת מין בזמן אמת

**הקשר:** סוכנת (נקבה) עונה, ועדיין לא יודעת מין הלקוח.

סוכנת: "שלום, הגעת ל-CLIX, מדברת מאיה. `[נייטרלי — עדיין לא יודעת]` איך אפשר לעזור?"

לקוח: "היי, רציתי לשמוע על השירות שלכם."

סוכנת: `[עדיין נייטרלי — "רציתי" לא חושף מין]` "בשמחה. `[עצירה]` על איזה תחום מדובר?"

לקוח: "אני מנהל מסעדה ואני צריך משהו לוואטסאפ."

סוכנת: `[עכשיו יודעת — "מנהל", "צריך" = זכר]` "אה, מעולה. אז **אתה** מקבל הרבה הודעות ולא מספיק לענות, נכון? `[עברה להטיית זכר]` תגיד לי, כמה הודעות ביום בערך?"

← שלושת המשפטים הראשונים נייטרליים. ברגע שהלקוח חשף מין ("מנהל"), הסוכנת עברה ל"אתה", "תגיד". זו בדיוק ההתנהגות האנושית.

**הגרסה ההפוכה:**
לקוח: "אני מנהלת מסעדה ואני צריכה משהו לוואטסאפ."
סוכנת: "אה, מעולה. אז **את** מקבלת הרבה הודעות ולא מספיקה לענות, נכון? תגידי לי, כמה הודעות ביום בערך?"

## 8. מלכודות מין נוספות

**רבים מעורב:** קבוצה מעורבת → זכר רבים ("אתם מוזמנים"). זה תקין בעברית.
**כבוד ברבים:** לפעמים פונים ליחיד ברבים לכבוד ("מה שלומכם") — בעברית זה פחות נפוץ מבצרפתית, השתמש במשורה.
**שמות יוניסקס:** שי, טל, נועם, ליאור, עדן, רון, אלמוג — **לא לנחש מין מהשם!** דבר נייטרלי עד שהלקוח חושף בהטיה. זו מלכודת ענקית.
**שם שאתה לא בטוח בהגייה שלו:** אם השם יכול להיות זכר או נקבה, אל תבנה עליו — חכה להטיה.

# חלק ב' — הומוגרפים והגייה מדויקת

עברית בלי ניקוד מלאה ב**הומוגרפים** — מילים שנכתבות זהה אבל נהגות שונה ומשמעותן שונה. סוכן צריך לדעת איזו הגייה מתאימה להקשר, אחרת הוא אומר מילה אחרת לגמרי.

## 9. ההומוגרפים הקריטיים — טבלת הכרעה

הפורמט: **כתיב** → הגייה א' (משמעות) / הגייה ב' (משמעות) → איך הסוכן יודע.

**חלֶב / חֵלֶב**
חָלָב (milk) / חֵלֶב (fat, tallow) → לפי הקשר. "כוס חלב" = chalav. כמעט תמיד chalav בשיחה עסקית.

**ספר**
סֵפֶר (book) / סַפָּר (barber) / סָפַר (counted) / סְפָר (border/frontier) → הקשר. "בית ספר" = sefer. "הלכתי לספר" = sapar.

**שמן**
שֶׁמֶן (oil) / שָׁמֵן (fat, adj.) → הקשר. "שמן זית" = shemen. "הוא שמן" = shamen.

**דוב / דב**
דֹּב (bear) / דּוּ (dual prefix) → נדיר בעסקי, בדרך כלל dov.

**אמן**
אָמָּן (artist) / אָמֵן (amen) / אִמֵּן (trained) → הקשר.

**מנה**
מָנָה (portion/dish) / מִנָּה (appointed) / מוֹנֶה (counter) → "מנה עיקרית" = mana.

**ברה / ברא / בריא**
בָּרִיא (healthy) → שים לב לכתיב מלא/חסר.

**חמה**
חַמָּה (sun/hot f.) / חֵמָה (rage) → הקשר. "מים חמים" מזכרי.

**מדינה**
מְדִינָה (country/state) — ברור, אבל שים לב ל**מוֹדִיעִין** (עיר) מול **מודיעין** (intelligence).

**עיר / עייר / עוּר**
עִיר (city) / עֵר (awake) / עוֹרֵר (wake up) → הקשר.

**רוח**
רוּחַ (wind/spirit) / רֶוַח (profit/space) → **קריטי בעסקי!** "רווח" (profit) נכתב לפעמים בלי ו כפולה. ודא הגייה: revach (profit) לא ruach (wind).

**ערב**
עֶרֶב (evening) / עָרֵב (guarantor) / עֲרָב (Arabia) / עָרַב (mixed) → "בערב" = erev. "ערב להלוואה" = arev.

**בקר / בוקר / ביקר**
בֹּקֶר (morning) / בָּקָר (cattle) / בִּקֵּר (visited/criticized) / בָּקַר (inspected) → "בבוקר" = boker. שים לב לכתיב.

**חשבון**
חֶשְׁבּוֹן (account/bill/math) — ברור, אבל "חשבון" בנק מול "חשבון" מתמטי — אותה הגייה, הקשר שונה.

**מס / מיס**
מַס (tax) / מֵס (melted) → "מס הכנסה" = mas.

**עוד / עד**
עוֹד (more/still) / עַד (until) → כתיב שונה אבל TTS מבלבל. "עד מחר" = ad. "עוד קפה" = od.

**כלה / כלא / כ"ל**
כַּלָּה (bride) / כָּלָא (imprisoned) / כָּלָה (finished/ended) → הקשר.

**מלח**
מֶלַח (salt) / מַלָּח (sailor) → "מלח ים" = melach.

**צהריים / צוהריים**
צָהֳרַיִם (noon) — הגייה: tsohorayim. TTS נוטה לשגות פה. ודא.

## 10. מספרים — הבעיה הכי גדולה של TTS עברי

מספרים בעברית **מוטים לפי מין הנמנה** (זכר/נקבה) ולפי מיקום (נפרד/נסמך). זה מבלבל כמעט כל TTS. הפתרון: **תמיד לכתוב מספרים במילים בכתיב שמכתיב את ההגייה הנכונה.**

**כלל הזהב של מספרים:**
- מספר שסופר עצם זכרי → צורת נקבה של המספר (!). "שלושה **ילדים**", "חמישה **שקלים**", "שני **בקבוקים**".
- מספר שסופר עצם נקבי → צורת זכר של המספר (!). "שלוש **בנות**", "חמש **דקות**", "שתי **שעות**".
- זו ההפכיות הידועה לשמצה. TTS טועה בזה תדיר.

**מקרים שכדאי לכתוב במילים כדי לכפות הגייה:**

| ספרה | לזכר (עצם זכרי) | לנקבה (עצם נקבי) |
|---|---|---|
| 1 | אחד (שקל אחד) | אחת (דקה אחת) |
| 2 | שני / שניים | שתי / שתיים |
| 3 | שלושה (שקלים) | שלוש (דקות) |
| 4 | ארבעה | ארבע |
| 5 | חמישה | חמש |
| 10 | עשרה | עשר |

**שעות — כתוב מפורש:**
- 8:00 → "שמונה בבוקר" / "שמונה בערב" (הוסף חלק יום כדי למנוע בלבול)
- 8:30 → "שמונה וחצי"
- 8:15 → "שמונה ורבע"
- 8:45 → "רבע לתשע" / "שמונה ארבעים וחמש"
- 14:00 → "שתיים אחר הצהריים" (לא "ארבע עשרה" בדיבור טבעי!)

**כסף — כתוב מפורש:**
- 250 ₪ → "מאתיים חמישים שקל"
- 1,200 → "אלף מאתיים"
- 3,500 → "שלושת אלפים חמש מאות"
- 10,000 → "עשרת אלפים"
- אחוזים: 20% → "עשרים אחוז"

**טלפון — קבוצות עם עצירות:**
- 052-777-4567 → "אפס חמש שתיים `[עצירה]` שבע שבע שבע `[עצירה]` ארבע חמש שש שבע"
- ספרות בודדות, לא "חמישים ושתיים"

**תאריכים:**
- 10.3 → "עשירי במרץ" / "עשירי לחודש"
- 2026 → "אלפיים עשרים ושש"

## 11. מילים לועזיות ש-TTS עברי הורס

כשמילה לועזית נכתבת באנגלית בתוך טקסט עברי, ה-TTS העברי לרוב יקריא אותה שגוי. **הפתרון: תעתיק עברי.**

| במקום (הרוס) | תעתיק עברי (נכון) |
|---|---|
| WhatsApp | וואטסאפ |
| email | אימייל |
| Google | גוגל |
| Instagram | אינסטגרם |
| Facebook | פייסבוק |
| online | אונליין |
| feedback | פידבק |
| link | לינק |
| SMS | אס-אם-אס |
| CRM | סי-אר-אם |
| PDF | פי-די-אף |
| OK | אוקיי |

**כלל:** אם חייבים אנגלית וה-TTS מקריא אותה מוזר — כתוב בתעתיק עברי פונטי. אם אפשר להימנע לגמרי — עדיף מילה עברית.

## 12. ראשי תיבות — כתוב אותם מפורש

## 13. שמות ומקומות — הגייה נכונה

- **שם שאתה לא בטוח בהגייתו** — עדיף לחזור על מה שהלקוח אמר, כפי שהוא אמר. "אז אמרת ש...ה שם שלך...?" והוא יתקן.

# חלק ד' — יישום ואינטגרציה

## 21. איך להזין את הסקיל לסוכן

**1. הבחנת מין → כלל בפרומפט המערכת:**
```
מין הפרסונה שלך: [זכר/נקבה]. דבר על עצמך בהתאם בהווה ובעתיד (בעבר ההטיה זהה).
מין הלקוח: לא ידוע בהתחלה. עד שהלקוח חושף מין (בשם או בהטיה), דבר בניסוחים נייטרליים. ברגע שזוהה מין — עבור להטיה הנכונה מיד.
```
אם יש CRM: `מין הלקוח: [ערך מהמערכת]`.

**2. מספרים → הוראה + few-shot:**
```
תמיד כתוב מספרים, שעות, מחירים וטלפונים במילים, בכתיב שמכתיב את ההגייה הנכונה. לעולם אל תכתוב ספרות שה-TTS עלול לשגות בהטייתן.
```

**3. תעתיק לועזי → הוראה:**
```
מילים לועזיות — כתוב בתעתיק עברי (וואטסאפ, אימייל, גוגל). אם אפשר, העדף מילה עברית.
```

**4. חלופות → הוראה כללית + טבלאות כדוגמה:**
```
העדף עברית מדוברת חמה על פני עברית רשמית. הימנע מ: הנני, ברצוני, לפיכך, אשמח לסייע, נציג יחזור אליך. במקומן השתמש בניסוחים טבעיים.
```

## 22. סצנת אימון מסכמת — הכל ביחד

**הקשר:** סוכן זכר (עומר, מכירות), לקוחה נקבה מזוהה מ-CRM כ"דנה".

עומר: `[יודע מ-CRM: נקבה]` "היי דנה! מדבר עומר מ-CLIX. `[עצירה]` תפסתי אותך בזמן טוב?"

דנה: "כן, בסדר."

עומר: "מעולה. `[הטיית נקבה כי דנה אישה]` אז **את** פנית אלינו לגבי אוטומציה לעסק, נכון? `[עצירה]` תגידי לי, על איזה תחום מדובר?"

דנה: "יש לי קליניקה לפיזיותרפיה."

עומר: `[קליטה]` "אה, פיזיותרפיה. `[עצירה]` **את** מטפלת בעצמך או שיש **לך** צוות? `[שים לב: לָךְ = lakh, נקבה]`"

דנה: "יש לי עוד שתי מטפלות."

עומר: `[מספר: שתי מטפלות — נקבי, אז 'שתי']` "אה, אז שלושתכן. `[עצירה]` יופי. תשמעי — הכאב הכי גדול אצל קליניקות זה תיאום תורים בוואטסאפ. זה גם אצלך?"

דנה: "בדיוק. אני עונה כל היום."

עומר: `[הודאה מחזקת + ספציפיות]` "כן, כל מטפלת אומרת לי את זה. `[עצירה]` תראי, אני אגיד לך את האמת — הבוט לא יפתור לך מאה אחוז, יש שאלות שתצטרכי לענות. אבל שמונים אחוז מהתיאומים? אוטומטי. זה חוסך משהו כמו שעה וחצי ביום. `[עצירה]` שווה לך שאני אשלח לך הצעה מסודרת עוד היום, עם מחיר מדויק?"

דנה: "כמה זה עולה בערך?"

עומר: `[מחיר במילים, ספציפי]` "רוב הקליניקות משלמות בין אלף וחמש מאות לאלפיים חמש מאות שקל בחודש. אני אשלח לך שלוש אופציות ותבחרי. `[עצירה]` המייל שלך?"

דנה: "dana, נקודה, פיזיו..."

עומר: `[חוזר על מה שנאמר]` "dana נקודה פיזיו..."

דנה: "שטרודל gmail נקודה com."

עומר: "שטרודל gmail נקודה com. `[עצירה]` יש לי. `[סוף אנושי + זיכרון]` יאללה דנה, מחכה לך מייל היום עד שש, ומזל טוב על הקליניקה — שלוש מטפלות זה כבר עסק אמיתי. `[עצירה]` יום טוב לך."

**מה קרה כאן:**
- הטיית נקבה עקבית לאורך כל השיחה כי דנה אישה: "את", "לך" (lakh), "תגידי", "תשמעי"
- "שתי מטפלות" — מספר נקבי נכון (שתי, לא שני)
- "שלושתכן" — נקבה רבים
- מחיר במילים
- אימייל עם "נקודה" ו"שטרודל"
- חזרה על מה שהלקוחה אמרה בזמן הקלדה
- הודאה מחזקת + ספציפיות + סוף אנושי

## 23. צ'קליסט סופי — הבחנת מין והגייה

לפני שחרור, ודא שהסוכן:

✓ פונה נייטרלית עד שמין הלקוח ידוע
✓ עובר להטיה נכונה מיד עם זיהוי מין
✓ עקבי במין הפרסונה של עצמו (הווה/עתיד)
✓ יודע ש"לך" = lekha (ז') / lakh (נ')
✓ לא מנחש מין משמות יוניסקס (שי, טל, נועם...)
✓ אומר מספרים במילים עם ההטיה הנכונה (שני/שתי, שלושה/שלוש)
✓ מוסיף חלק יום לשעות ("שמונה בבוקר")
✓ מקריא טלפון בספרות בודדות עם עצירות
✓ כותב מילים לועזיות בתעתיק עברי
✓ מפרש ראשי תיבות (וכו' → "וכן הלאה")
✓ מחליף עברית רשמית בעברית מדוברת חמה
✓ מנווט הומוגרפים לפי הקשר (רווח≠רוח, ערב≠ערב)
✓ מגוון מילות מילוי, לא חוזר על אותה פעמיים

אם כל אלה מסומנים — הסוכן מדבר עברית מושלמת. תשחרר.

## הערה אחרונה

עברית היא שפה שנשענת על ההקשר יותר מרוב השפות — הכתב לא נותן את כל המידע, והדובר משלים אותו מהמשמעות. סוכן קולי טוב בעברית הוא סוכן ש**מבין את המשמעות** לפני שהוא הוגה את המילה, בדיוק כמו קורא אנושי שיודע אוטומטית ש"בבוקר" זה boker ולא bakar.

זה בדיוק מה שהמסמך הזה נותן למודל: לא רשימת מילים, אלא **את היכולת לדעת איזו הגייה מתאימה לאיזה רגע** — וזו בדיוק ההבחנה שבן אדם עושה בלי לחשוב, ורובוט חייב ללמוד.

יאללה, תבנה סוכן שמדבר עברית כמו שנולד לתוכה.
