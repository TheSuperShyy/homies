# Dashboard UI kit

Recreation of the dark reference dashboard ("Stovest"), built from the system components (`window` bundle namespace) + tokens. `index.html` is interactive: range tabs, filter tabs, sidebar nav, and a **dark/light theme toggle** in the topbar (light mode = Skillset palette, same layout).

Screens: single dashboard view (the only screen in the source material). Avatar photos were not extractable from screenshots — initials fallback is used.
