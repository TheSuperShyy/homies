Pill-shaped button; use `primary` sparingly (one per view), `secondary` for toolbar actions ("See all"), `ghost` for tertiary.

```jsx
<Button variant="secondary" size="sm">See all</Button>
<Button variant="primary">Upgrade</Button>
```

Variants: primary | secondary | ghost. Sizes: sm 30px, md 38px, lg 46px. All fully rounded.
